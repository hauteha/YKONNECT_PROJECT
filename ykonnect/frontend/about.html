À propos de YKonnect

Une plateforme inspirée d’IT-Connect pour centraliser des contenus techniques IT, avec un chatbot capable de s’appuyer sur la base d’articles et le web.

Vision

L’objectif de YKonnect est de fournir un point d’entrée unique pour la connaissance IT : administration système, réseau, sécurité, cloud, DevOps. Le chatbot sert d’interface intelligente capable de :

  • Rechercher d’abord dans la base d’articles interne.
  • Compléter au besoin avec des informations issues du web.
  • Référencer systématiquement les sources utilisées.

Architecture cible

À terme, l’architecture pourra s’articuler autour :

  • Une BDD relationnelle (ex : PostgreSQL) pour les articles, tags, utilisateurs.
  • Une API backend (REST / GraphQL) pour exposer la connaissance.
  • Un moteur de recherche (full-text + vectoriel) exploité par le chatbot.
  • Un front en SPA ou SSR selon les choix techniques.
